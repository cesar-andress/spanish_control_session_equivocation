Zenodo DOI: https://doi.org/10.5281/zenodo.23496446

Reproducibility update with the public unit-level evidence table.

This patch release adds `data/HUMAN_EVIDENCE_67_PUBLIC.csv` (67 independently
double-coded OOP units; anonymous `coder_A` / `coder_B` labels), a data
dictionary, and public recomputation of the locked agreement statistics
(`scripts/reproduce_public_agreement.py`).

Explicitly:

- **no scientific result changed**;
- **no labels changed**;
- **no new annotation occurred**.

Source full texts, free-text annotator comments, and original return documents
remain excluded. No XIV responsiveness outcomes are included.

# v1.0.0

First stable public research package for Zenodo archival.

This release provides reproducible materials for a methodological study of
expert coding of Spanish prime-ministerial control-session replies:

- protocols and instruments used in the sequential measurement programme
  (development, calibration rounds, binary redesign drafts);
- identifier-only XIV target-frame metadata (N=100 context; no reply outcomes);
- aggregate locked agreement summaries;
- analysis code, schemas, and manifests;
- tables/figures used in the measurement-paper workflow;
- licensing and provenance documentation.

The package documents measurement behaviour and stopping decisions under
prospectively fixed gates. It does **not** claim that the reply-status or
direct-resolution instruments were successfully validated for main annotation,
and it does **not** include substantive XIV responsiveness outcomes.
