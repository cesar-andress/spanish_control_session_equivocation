## Before any public data release

1. Pin source versions and checksums.
2. Quote the applicable licence clauses.
3. Attribute upstream corpora as required.
4. Update this file and `CITATION.cff` accordingly.
5. Record the decision in `protocol/DECISIONS.md`.
